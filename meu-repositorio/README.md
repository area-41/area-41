# 🔭 Observatório Demográfico — PyScript & Pandas

Aplicação Web de demonstração executando computação científica em Python diretamente no navegador através de **WebAssembly (Pyodide / PyScript)** e **Pandas**, estruturada com layout de documentação e navegação *ScrollSpy*.

### 🚀 Tecnologias
* **PyScript / Pyodide** (Python no Browser via WebAssembly)
* **Pandas** (Manipulação de dados em memória)
* **HTML5 / CSS3 Moderno** (Sidebar fixa e layout responsivo)
* **JavaScript Intersection Observer API** (*ScrollSpy* dinâmico)
